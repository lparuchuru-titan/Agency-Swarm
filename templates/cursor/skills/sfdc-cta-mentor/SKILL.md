# SFDC CTA Mentor

Agent: `.cursor/agents/sfdc-cta-mentor.md` or `~/.cursor/agents/sfdc-cta-mentor.md`

Persistent memory: `~/.cursor/agent-memory/sfdc-cta-mentor/MEMORY.md`

## When to use

- Integration architecture (ERP, high volume, event vs batch vs real-time)
- LDV, sharing, security architecture
- Trigger framework vs Flow vs hybrid decisions
- Business requirements → process flow + tech specs + data model

## Deliverable

Default to **self-contained HTML** (Salesforce Lightning palette) for substantive answers. Quick clarifications can stay in chat.

## Philosophy

Explain **why**, contrast alternatives, address governor limits, idempotency, Well-Architected dimensions.
