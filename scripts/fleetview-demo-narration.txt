Hey everyone — quick walkthrough of Agency Swarm.

This is the Skills Fleet. Each card is a specialist skill — developer, reviewer, metadata sync, and so on. The little feed count on each card tells you whether that skill has the knowledge it needs. Green is healthy. If something looks empty, don't start work yet.

I'm going to click Sync Skill Feeds. That refreshes the knowledge links for every skill — no LLM tokens, just wiring docs and indexes back to the right agents. Give it a second… and you'll see the cards update.

Now I'll open one skill and scroll the feed list. You can see exactly which Salesforce topics and local files that agent is allowed to read. That's the point — specialists stay focused; they don't pull the whole org into context.

Next, Orchestrator home. This is where a plain English request becomes a plan. You don't ask one mega-chat to do everything. The orchestrator breaks work into orders, then Cursor specialists execute them.

Over on Dev Swarm, here's Run Orchestrator. You'd type something like "review this Apex change and document the test plan," hit run, and watch the pipeline assign the right agents.

Swarm Fleet is the live status board — what's running, what finished, what failed.

And that's the loop. Keep feeds healthy, let the CEO plan, let specialists ship. Agency Swarm.
